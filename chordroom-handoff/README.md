# ChordRoom — Design handoff for Claude Code

อ่าน `SPEC.md` ก่อน: เป็นสเปกหลัก (flow, พฤติกรรม, ระบบสี, สถาปัตยกรรม, ลำดับการทำ)

## โฟลเดอร์ `design/`

ไฟล์ `.dc.html` คือดีไซน์จาก canvas ใช้เป็น **ต้นแบบหน้าตา** (layout, ขนาด, สี, ข้อความ) ไม่ใช่โค้ดที่เอาไปรันตรงๆ

- ไฟล์พวกนี้ใช้ runtime ของเครื่องมือออกแบบ (`support.js`, แท็ก `<x-dc>`, `<sc-if>`, `<dc-import>`) **เปิดในเบราว์เซอร์ตรงๆ ไม่ได้**
- สีเขียนเป็น `{{t.ชื่อtoken}}` ค่าจริงอยู่ใน `<script>` ท้ายไฟล์ (ชุดสว่าง/มืด) และในตาราง Tokens ของ `SPEC.md` → ให้ทำเป็น CSS variables + class `dark`
- สไตล์เขียนแบบ inline ทั้งหมด → แปลงเป็น Tailwind/คอมโพเนนต์ React ตามโครงไฟล์ใน `SPEC.md`
- เนื้อคอร์ดในกรอบ (แถบเทา + คอร์ด) และชื่อเพลง/ศิลปินเป็น **ข้อมูลตัวอย่าง** ห้ามใช้เป็นข้อมูลจริง

### รายการไฟล์

| ไฟล์ | หน้าจอ |
|---|---|
| `B-Home` `B-Join` `B-Search` `B-Song` `B-Invite` | มือถือ: หน้าแรก · เข้าห้อง · ค้นหา · เพลงตอนนี้ (แท็บคอร์ดแยก) · ชวนเพื่อน |
| `B-THome` `B-TJoin` `B-Tablet` `B-TSlide` `B-TInvite` | ไอแพด: หน้าแรก · เข้าห้อง · แบ่งจอกับ Safari · ห้องลอย (แนวตั้ง) · ชวนเพื่อน |
| `B-DHome` `B-DJoin` `B-DeskRoom` `B-DeskFloat` `B-DSearch` `B-DInvite` | คอม: หน้าแรก · เข้าห้อง · ห้อง · หน้าต่างลอย · ค้นหา Ctrl+K · ชวนเพื่อน |
| `S-Song` `S-Tablet` `S-TPortrait` `S-Desk` | ทางเลือก “ฝังหน้าคอร์ดในหน้าเดียว” — ใช้ได้เฉพาะเว็บที่ยอมให้ฝัง iframe (3 เว็บหลักไม่ยอม) |

ขนาดออกแบบ: มือถือ 390×844 · ไอแพด 1180×820 (แนวตั้ง 820×1180) · คอม fluid ออกแบบที่ 1440 กว้าง

## ข้อห้ามสำคัญ

- ห้ามดึง/เก็บ/แสดงเนื้อคอร์ดหรือเนื้อเพลงจากเว็บต้นทาง และห้ามทำ proxy ตัดการห้ามฝัง
- index เพลงเก็บได้แค่ ชื่อเพลง ศิลปิน ลิงก์
